# 角色素材

角色按用户提供的米格瑞特（Migrate）设定参考图，以内置 imagegen 工具生成 Q 版桌宠姿态，再以该工具清理背景。原始参考海报未包含在仓库中。代码使用 MIT 许可证；原始角色设定的权利归原权利人。

- `migrate-atlas.png`：4 列 × 2 行，依次为正面、挥手、侧面、背面、困倦、施法、开心、说话。
- `idle.png` 等八张：从 atlas 等分裁切，透明 PNG。
- `portrait.png`、`icon.png`、`icon.ico`：从正面图裁切、缩放和封装。
- `tray.png`：独立绘制的罗盘标记。

最终提示词要点：参考银色长发、蓝眼、白/海军蓝宽檐羽毛帽、层叠白裙、金色罗盘与锚、蓝色航海法杖，生成统一三头身、完整身体、八姿态的 4×2 图集；各格同尺度、留透明间隔，无文字、水印或场景。第二次以背景提取模式要求保持八个人物与格位，删除灰色纹理和雾气，空白区域使用真实 alpha=0。

生成方式：内置 imagegen；未调用需要用户 API Key 的 CLI。`npm run assets` 可从已提供的图集重新裁切素材，不会再次调用 AI。

音乐未打包进本项目。在线播放链接指向原作 `https://www.bilibili.com/video/BV1wT4y1k7Pw/`；本地音频由使用者自行选择，既不复制到项目也不上传。

## 生活小剧场

新增素材同样由内置 imagegen 生成，角色外形参考本项目原有图集，未使用其他 API Key。

- `scenes-atlas.png`：4×2 透明图集，邀请、海边同行、端碗、抬勺、吃一口、开心咀嚼、请吃草莓蛋糕、请吃焦糖布丁。要求八格人物完整、同一角色、连续吃饭姿态位置一致，真正透明背景，无文字或场景。
- `scene-*.png`：从图集裁切、等比缩放，不拉伸人物。
- `home-backgrounds-atlas.png`：2×1 场景背景图集。左边为通往蓝顶灯塔小屋的海岸小路；右边为有海景拱窗、书架、蓝色沙发的温暖客厅。要求前景留出放置人物与餐桌的空间，无人物、食物或文字。
- `scene-home.jpg` / `scene-coast.jpg`：从背景图集裁切的两个背景。

场景中的餐桌、餐盘、蛋糕与布丁的额外前景特效由代码绘制。`npm run assets:scenes` 可从现有图集重新生成场景素材，不调用 AI。
