# csp-migrate · 米格瑞特桌宠

**v1.0.3 · 海风来信**：桌边又多了一点小小的心意。愿每次抬头，都能遇见她的好心情 w [看看这封来信](CHANGELOG.md)

银发、蓝眼、航海法杖，还有一小片海风。基于用户提供的米格瑞特（Migrate）设定制作的 Windows 透明桌面伙伴。

感谢 **LA 群用户 pbds_** 提供角色设定。人物素材使用内置 imagegen 工具生成，动画、界面与程序由 Codex 协助制作；具体生成方式和提示词见 [素材说明](assets/README.md)。

角色设定为 **15 岁的航海少女**，活泼、好奇、机灵，偶尔俏皮，做题时认真可靠。初期版本的默认角色设定会在启动时更新；自行编辑过的角色设定会保留。

## 直接使用

从 [Releases](https://github.com/0103abc/csp-migrate/releases) 下载 `Migrate-1.0.3-win-x64.zip`，**完整解压**后运行 `Migrate.exe`。无需安装 Node.js；请保留 exe 同目录下的运行文件。

首次出现于主屏幕工作区右下角，自动避开任务栏。支持 Windows 10/11 x64。

| 操作           | 作用                                               |
| -------------- | -------------------------------------------------- |
| `Ctrl+Alt+M`   | 全局显示 / 隐藏，设置中可修改                      |
| 拖动角色       | 移动位置并记住位置                                 |
| 单击 / 双击    | 挥手 / 打开对话                                    |
| 右键角色       | 托盘式菜单、所有动作与退出                         |
| 底部 `↻` / `✧` | 转身 / 潮汐魔法                                    |
| 底部 `♫`       | 打开《白鸟过河滩》播放器                           |
| 底部 `题`      | 打开 QOJ 上 CSP-S 2026《迁徙》题面                 |
| 底部 `⚙`       | API 与桌面偏好                                     |
| 底部 `−`       | 隐藏，程序仍留在系统托盘                           |
| 托盘图标       | 双击切换显隐；右键显示、设置、动作、回右下角与退出 |

使用八种绘制姿态配合呼吸、摆动、跳跃、行走与说话动画。转身会显示单独绘制的背面，散步和拖动会显示侧面。支持自动小动作、70%–150% 大小、置顶及可选开机启动。

「设置 → 桌面偏好 → 界面与对话语言」可选 **简体中文**、**繁體中文（香港）** 或 **繁體中文（台灣）**，默认简体中文。界面、气泡、系统托盘、赛程时间格式与后续 AI 回复跟随所选语言；台湾模式采用「滑鼠、網路、軟體、儲存」等用语。繁体转换使用随应用打包的 OpenCC 地区词典，离线完成。

转身采用 **16 角度序列**，固定脚底锚点与整体尺度，通过逐帧混合及缓入缓出完成约 1.54 秒的半转身；转回时反向播放。待机正面与背面直接取自序列端点，像素、色彩与透明度保持一致，切换时不叠加淡出淡入。快速点击会合并为下一次转身请求，其他动作可立即打断；「回身看海」会停留片刻再转回。

## 离线互动与题面

「互动」页提供 **20 种动作、46 组共 460 句原创台词**。包含日常、时间、三餐、喝水、伸展、摸头、眨眼、跳跃与小发现等分组。同组以打乱的列表轮换，抽完一组前不会重复，也避免跨轮连续重复。全部在本地完成，不调用 API。

开启自动动作与「跟着时间说话」后，她会按本机时间选择早晚问候、早餐（07:30–09:30）、午餐（11:30–13:30）、晚餐（17:30–19:30）等动作与台词。喝水与伸展约半小时轮换，整点报时可单独开启（默认关闭、不播放声音）。定时互动至少相隔 10 分钟，每个餐段每天只提醒一次；忙于动作时顺延，隐藏后不集中补播。互动页的「听听现在的海风」也可手动触发当前时段台词。

动作包括挥手、连续转身、开心、点头、摇头、轻跃、伸展、害羞、摇摆、漂浮、海鸟特效、潮汐魔法、回身看海、探头、打盹及向左/右散步。它们使用已绘制姿态与程序动画组合。

默认待机站稳，仅有很轻的纵向呼吸，不会持续左右摇晃。主要手动动作是 5–8.5 秒的分段演出，使用姿态渐变、准备、展开、停顿与收势；自动动作默认约 90 秒一次，可改为 45 秒、3 分钟、5 分钟或完全关闭。摇摆只作为手动动作提供。

鼠标在头部停留约 0.35 秒时，她会害羞地轻轻摇头、脸红并回应；离开再回来有约 10 秒冷却，拖动和当前大动作期间不会触发。互动页可手动眨眼或跳起来。开启「活泼的小伙伴」与自动动作时，会自然眨眼、偶尔歪头看看，白天的大动作也更偏向轻快的回应；不会持续来回摇晃。

「互动」页另有四段 **24–32 秒的生活小剧场**：一起吃饭、去她的灯塔小屋做客、请你吃草莓蛋糕、请你吃焦糖布丁。去小屋时会在门外停下、脱鞋并把鞋摆好，再赤脚进屋迎客；门口的鞋子仍留在门外。场景可暂停、继续、重播或结束，切换到其他页时自动暂停，全部在本地播放。

题面入口位于桌宠底部「题」、互动页和右键菜单，打开 [QOJ #24562 · CSP-S 2026《迁徙》](https://qoj.ac/problem/24562/statement/zh_cn)；香港模式打开 `yue_hk`，台湾模式打开[正體中文（台灣）题面](https://qoj.ac/problem/24562/statement/zh_tw)。不提交代码、不代为登录。

## Codeforces / AtCoder 比赛提醒

在「设置 → 比赛赛前提醒」中分别开关两个平台，默认开启；「比赛」页显示接下来的公开赛程、更新时间和网络状态，点击比赛可在浏览器打开官方页面。比赛报名仍需自己完成。

- 使用 [Codeforces 官方 contest.list API](https://codeforces.com/apiHelp/methods?locale=en) 的 `BEFORE` 常规比赛（不包含 Gym），以及 [AtCoder 官方赛程页](https://atcoder.jp/contests/?lang=en) 的预定比赛与每日比赛。
- 每 10 分钟获取赛程、每 15 秒检查一次，到开赛前 **5 分钟**时显示不抢焦点的桌面小窗口与系统通知。小窗口约 45 秒后自动关闭，可点击查看比赛。时间和时区均由本机转换显示。
- 隐藏桌宠后仍会提醒，与自动动作开关互相独立。**程序需保持运行且电脑处于唤醒状态**；首次获取和刷新需要网络，退出或休眠时无法弹窗。赛前 5 分钟内启动，会在获取赛程后补提醒；比赛已经开始则不追补。
- 公开赛程与已提醒记录单独缓存在 `%APPDATA%/csp-migrate/contest-cache.json`，避免重启重复提醒。断网时最多使用 24 小时内的缓存，失败状态会显示在赛程页。系统通知遵从 Windows 免打扰设置，应用内提醒仍独立显示。
- 不需要 Codeforces / AtCoder 账号或任何 API Key；赛程请求不带 DeepSeek 密钥，不读取比赛登录信息。

## 设置 DeepSeek

1. 点击 `⚙`，在 **API Key** 中填入自己的密钥。
2. 默认地址为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`。可手动修改地址与模型。
3. 点击 **保存并测试连接**，成功后切到「对话」。测试会发起一次真实 API 调用。

支持 OpenAI 兼容的 Chat Completions 流式接口、中文增量回复、停止回复、多轮上下文与自定义角色设定。`Enter` 发送，`Shift+Enter` 换行。

密钥只在 Electron 主进程处理，通过 Windows DPAPI（Electron safeStorage）加密后保存。界面不会读取保存的密钥，也不会收到密文。设置位于 `%APPDATA%/csp-migrate/settings.json`（开发与打包后的应用名保持一致）。密钥无法随配置迁移到其他 Windows 账户；请重新填写。聊天记录只保存在当前进程内存中；退出或清空后移除。对话会发送至你在设置中填写的 API 服务。应用不执行模型返回的电脑指令。

## 《白鸟过河滩》

音符按钮打开听歌页，使用 Bilibili 原作内嵌播放器（[ilem / 洛天依原作](https://www.bilibili.com/video/BV1wT4y1k7Pw/)），另有浏览器打开按钮。在线视频可能受地区、平台、登录与浏览器自动播放策略影响；必要时在播放器内点击播放。

也可选择本机 MP3、WAV、OGG、FLAC、M4A 音频，提供播放、暂停、进度、音量与循环。音频仅由用户选择后在本机读取，不上传、不写入仓库，重启后需重新选择。仓库与发行包不附带歌曲文件。隐藏桌宠或关闭面板不会终止正在播放的音乐，可回到听歌页暂停；退出程序结束播放。

## 本地开发

安装 Node.js 22.12+（建议当前 LTS，含 npm）与 Git：

```sh
npm ci
npm start
```

若所用 npm 默认禁用依赖安装脚本，Electron 首次需要下载运行时：

```sh
node node_modules/electron/install.js
```

```sh
npm test       # 核心测试，离线，不需要 API Key
npm run test:ui # Windows 桌面集成测试：本机 mock API + 测试密钥 + 测试音频
npm run build  # 生成 dist/Migrate-win32-x64/Migrate.exe
npm run check:secrets # 检查 Git 跟踪文件与历史中的密钥模式
```

构建使用 Electron 45.3.2 / Chromium。若已经下载官方 Electron zip，可设置 `ELECTRON_ZIP_DIR` 为 zip 所在目录，构建时重复利用；文件名需为 `electron-v45.3.2-win32-x64.zip`。制作发行 zip 时压缩 `dist/Migrate-win32-x64` 内的全部内容。

开发时可执行 `git config core.hooksPath .githooks` 启用推送前的密钥检查。`.env`、个人设置、依赖、构建结果与私钥文件已加入忽略规则。不要把真实密钥写入源码、测试、README 或截图。密钥检查用于增加保护，不能替代妥善管理凭据。

## 项目结构与素材

- `src/main.cjs`：窗口、托盘、快捷键、拖动、多屏、配置、密钥和 API。
- `src/core.cjs`：接口参数、SSE 解析、历史边界与窗口位置。
- `src/contests.cjs` / `src/reminder.*`：官方赛程、持久化去重与赛前提醒窗口。
- `src/time-dialogue.js` / `src/clock-events.js`：时段台词、三餐与休息事件。
- `src/turn-player.js`：16 角度转身序列与插值播放。
- `src/preload.cjs`：明确限定的 IPC 接口；渲染器隔离且禁用 Node.js。
- `src/pet.*` / `src/panel.*`：桌宠与对话 / 听歌 / 设置面板。
- `assets/`：八姿态透明 PNG、图集、头像与图标；生成说明见 [assets/README.md](assets/README.md)。
- `test/`：核心测试与 Windows Electron 端到端测试。

代码采用 MIT 许可证；角色原设定及第三方音乐的权利归各自权利人。桌宠动画是绘制姿态、16 角度转身序列与程序动画组合，并非 Live2D 或 3D 骨骼模型。

接口与窗口实现参考：[DeepSeek 官方文档](https://api-docs.deepseek.com/)、[Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)、[globalShortcut](https://www.electronjs.org/docs/latest/api/global-shortcut)、[safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)。
